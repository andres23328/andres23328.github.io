# Portafolio de Andrés Felipe Ardila

Sitio estático (HTML, CSS y JavaScript sin dependencias). Responsive, con tema claro y oscuro.

## Ver en tu computador
Abre `index.html` en el navegador.

## Publicarlo gratis con GitHub Pages
1. Crea un repositorio público llamado `andres23328.github.io`.
2. Sube todo el contenido de esta carpeta (no la carpeta en sí).
3. En Settings > Pages, elige la rama `main` y la carpeta `/ (root)`.
4. Tu sitio queda en `https://andres23328.github.io`.

## Estructura
- `index.html`: contenido
- `css/styles.css`: estilos y colores (variables al inicio)
- `js/main.js`: tema, menú móvil y animaciones al hacer scroll
- `assets/foto.jpg`: tu retrato (reemplázalo por otro cuadrado si quieres)
- `assets/Portafolio_Profesional.pdf`: PDF descargable
